================================================================
WHY THIS WORKS
================================================================

1. The login form doesn't sanitize input
2. The SQL query becomes:
   SELECT * FROM Users WHERE email = '' OR '1'='1'--' AND password = 'x'
   
3. The OR '1'='1' makes the WHERE clause always true
4. The -- comments out the rest of the query
5. Result: Authentication bypass!

================================================================
DEFENSE MEASURES (What Juice Shop Should Do)
================================================================

1. Use parameterized queries/prepared statements
2. Input validation and sanitization
3. Use strong password hashing (bcrypt instead of MD5)
4. Implement rate limiting
5. Add Web Application Firewall (WAF)
6. Log and monitor suspicious queries
