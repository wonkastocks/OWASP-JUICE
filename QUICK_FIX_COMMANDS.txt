QUICK FIX FOR BAD GATEWAY ERROR
================================

SSH to your server:
ssh root@155.138.197.128

Then run these commands:

1. Check Docker status:
docker ps -a

2. Restart the container:
docker restart juice-shop
OR
docker restart juice3
OR (if no container exists)
docker run -d --name juice-shop --restart unless-stopped -p 3000:3000 bkimminich/juice-shop

3. Check if it's running:
docker ps
curl http://localhost:3000

4. Check Apache:
systemctl restart apache2

5. Check Cloudflare tunnel (if using):
ps aux | grep cloudflared

The bad gateway usually means:
- Docker container crashed/stopped
- Port 3000 not responding
- Apache proxy can't reach backend
